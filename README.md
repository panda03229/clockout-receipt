# 퇴근 영수증 (PWA)

오늘 번 돈이 초 단위로 쌓이고, 퇴근하면 영수증 한 장으로 남는 웹앱입니다.
아이폰에서 "홈 화면에 추가"하면 앱처럼 열립니다. 애플 개발자 계정은 필요 없습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 계산, 저장) |
| `manifest.json` | 앱 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 오프라인 실행 (서비스 워커) |
| `icons/` | 홈 화면 아이콘 (180, 192, 512px) |

기록은 각 기기의 IndexedDB에만 저장됩니다. 서버로 전송되는 데이터는 없습니다.

## GitHub Pages로 무료 배포하기

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
   - Repository name: `clockout-receipt` (원하는 이름)
   - **Public**으로 선택합니다. 무료 계정의 GitHub Pages는 공개 저장소만 됩니다.
   - **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더 안의 파일을 **전부** 끌어다 놓습니다 (`index.html`, `manifest.json`, `sw.js`, `README.md`, `icons` 폴더).
   - `icons` 폴더가 통째로 안 올라가면 폴더째로 드래그해 보세요.
   - **Commit changes**를 누릅니다.
5. 저장소의 **Settings** → 왼쪽 **Pages**에서
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다.
   예: `https://<내아이디>.github.io/clockout-receipt/`

## 아이폰에 설치하기

1. 아이폰 **사파리**로 위 주소를 엽니다. 크롬 앱에서는 홈 화면 추가가 제한될 수 있습니다.
2. 아래쪽 **공유** 버튼 → **홈 화면에 추가** → **추가**
3. 홈 화면의 "퇴근 영수증" 아이콘으로 실행합니다.

안드로이드는 크롬으로 열고 메뉴 → **홈 화면에 추가** (또는 "앱 설치")를 누르면 됩니다.

## 수정한 버전을 다시 올릴 때

1. 저장소에서 바뀐 파일을 다시 업로드합니다 (같은 이름이면 덮어씁니다).
2. `sw.js` 맨 위 `VERSION = "v1"`을 `"v2"`처럼 올려서 함께 업로드합니다.
   이걸 안 하면 휴대폰이 예전 버전을 계속 보여줄 수 있습니다.
3. 휴대폰에서 앱을 완전히 닫았다가 다시 열면 새 버전이 적용됩니다.

## 알아 둘 점

- 저장소가 공개라서 **코드는 누구나 볼 수 있습니다.** 기록(연봉, 사진)은 각자 기기에만 있어서 공개되지 않습니다.
- 사파리 데이터를 지우거나 앱을 홈 화면에서 지우면 기록도 함께 지워질 수 있습니다.
- 첫 실행 때 인터넷이 필요합니다 (글꼴, 이미지 저장 도구를 받아 옴). 그다음부터는 오프라인에서도 열립니다.
